la logique de conversion entre plusieurs bases

Extrait de code

// Exemple: Conversion manuelle en hexadécimal
@Override
public String toBase(String input) {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < input.length(); i++) {
        int ascii = input.charAt(i);
        String hex = toHex(ascii);
        sb.append(hex);
        if (i < input.length() - 1) {
            sb.append(" ");
        }
    }
    return sb.toString();
}

private String toHex(int value) {
    if (value == 0) return "0";
    StringBuilder hex = new StringBuilder();
    int v = value;
    while (v > 0) {
        int digit = v % 16;
        char hexChar = (char) (digit < 10 ? '0' + digit : 'a' + (digit - 10));
        hex.insert(0, hexChar);
        v /= 16;
    }
    while (hex.length() < 2) {
        hex.insert(0, '0');
    }
    return hex.toString();
}

Explication

Pour chaque caractère de la chaîne, on récupère sa valeur ASCII, puis on la convertit manuellement dans la base cible (ici, hexadécimal) sans utiliser les fonctions intégrées de Java. On effectue la division répétée pour obtenir chaque chiffre de la base, qu'on assemble dans l'ordre correct. Le processus inverse permet de revenir du code base vers le texte d'origine. Cette logique est appliquée pour toutes les bases (binaire, octal, décimal, hexadécimal).

La logique de réversibilité et d'intégration du chiffrement/déchiffrement (chiffre de César)

Extrait de code

// Chiffrement et déchiffrement de César
@Override
public String encrypt(String input, int key) {
    StringBuilder sb = new StringBuilder();
    for (char c : input.toCharArray()) {
        if (c >= 'A' && c <= 'Z') {
            sb.append((char) ('A' + (c - 'A' + key) % 26));
        } else if (c >= 'a' && c <= 'z') {
            sb.append((char) ('a' + (c - 'a' + key) % 26));
        } else if (c >= '0' && c <= '9') {
            sb.append((char) ('0' + (c - '0' + key) % 10));
        } else {
            sb.append(c);
        }
    }
    return sb.toString();
}

@Override
public String decrypt(String input, int key) {
    StringBuilder sb = new StringBuilder();
    for (char c : input.toCharArray()) {
        if (c >= 'A' && c <= 'Z') {
            sb.append((char) ('A' + (c - 'A' - key + 26) % 26));
        } else if (c >= 'a' && c <= 'z') {
            sb.append((char) ('a' + (c - 'a' - key + 26) % 26));
        } else if (c >= '0' && c <= '9') {
            sb.append((char) ('0' + (c - '0' - key + 10) % 10));
        } else {
            sb.append(c);
        }
    }
    return sb.toString();
}

Explication

Le chiffrement de César décale chaque lettre ou chiffre d'un certain nombre de positions dans l'alphabet ou la suite numérique, selon la clé fournie. Cette logique est appliquée avant la conversion en base (pour chiffrer) ou après la reconversion en texte (pour déchiffrer), assurant ainsi la réversibilité du processus. Le même algorithme, avec la clé en sens inverse, permet de retrouver le texte d'origine. L'intégration dans le programme permet à l'utilisateur de choisir de chiffrer ou déchiffrer à chaque étape de conversion.

Explication

// Exemple : Extrait du programme principal
public static void main(String[] args) {
    Scanner scanner = new Scanner(System.in);
    if (hasCommandLineArgs(args)) {
        handleCommandLineMode(args, scanner);
    } else {
        handleInteractiveMode(scanner);
    }
}

private static boolean hasCommandLineArgs(String[] args) {
    boolean hasInput = false;
    boolean hasBase = false;
    for (int i = 0; i < args.length - 1; i++) {
        if (args[i].equals("--input")) {
            hasInput = true;
        } else if (args[i].equals("--base")) {
            hasBase = true;
        }
    }
    return hasInput && hasBase;
}
